# ToDo Application

Простое и эффективное приложение для управления задачами, построенное на FastAPI с SQLite базой данных. Контейнеризировано с помощью Docker для легкого развертывания.

**Docker Hub:** [mid9906/to_do25_07](https://hub.docker.com/r/mid9906/to_do25_07)

## Особенности

- Создание, чтение, обновление и удаление задач (CRUD)
- Фильтрация задач по статусу выполнения
- Поиск по названию и описанию задач
- Автоматическая инициализация базы данных
- Автогенерируемая документация Swagger/OpenAPI
- Docker-контейнеризация для простого запуска

## Технологии

- **Python 3.11**
- **FastAPI** - веб-фреймворк
- **SQLite** - встроенная база данных
- **Uvicorn** - ASGI-сервер
- **Docker** - контейнеризация

## Быстрый старт

Запустите приложение одной командой:

```bash
docker run -d --name todo-app -p 8000:8000 mid9906/to_do25_07
```
